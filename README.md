# Home Network Setup and Configuration

Configuration and troubleshooting of a small home network connecting multiple devices through a wireless router.

## What I Did
- Configured and managed a small home network connecting multiple devices through a wireless router.
- Verified connectivity using `ipconfig`, `ping`, and `tracert`, and performed basic network troubleshooting.
- Secured the Wi-Fi network using WPA2/WPA3 encryption.

## Tools Used
- Windows command line (`ipconfig`, `ping`, `tracert`)

## Concepts Covered
- IP addressing and DNS basics
- LAN/WAN concepts
- TCP/IP fundamentals
- Wi-Fi security (WPA2/WPA3)
